# Early-Bird Entry Registration

This context covers how an eligible early-bird guest claims one event entry time.

## Language

**Eligible Gmail**:
A normalized Gmail address imported from the approved Luma guest list and allowed to make one entry registration.
_Avoid_: Account, login

**Entry Registration**:
The one-time assignment of one Eligible Gmail to one Entry Time. It always consumes exactly one Capacity Place, even when the Luma source recorded more than one ticket under that Gmail.
_Avoid_: Group booking, party reservation

**Source Ticket Count**:
The number of approved Luma tickets observed under an Eligible Gmail for import reconciliation only. It does not change how many Capacity Places an Entry Registration consumes.
_Avoid_: Party size, reservation quantity

**Capacity Place**:
One attendee place within an Entry Time. One Entry Registration consumes one Capacity Place.
_Avoid_: Source ticket

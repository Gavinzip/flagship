# 韓國卡展頁：背景與構圖檢查

日期：2026-09-14。下方保留重做前的問題定位；本輪已完成韓國內頁重構，實作與驗證更新見文末。

## 使用者的判斷

目前韓國卡展網站很單調，第一頁之後缺少特色；需要讓海報的視覺延續到整個頁面。素材先集中並固定編號，讓 Gavin 與後續 agent 能指向同一張圖。

## 實際檢查

Codex 內建瀏覽器，1280 × 720，本機既有建置 `http://127.0.0.1:4178/korea/?lang=zh-TW&theme=dark`。實際捲動首屏，並點「查看韓國場資訊」確認到達城市段。這不是正式網站上線驗證。

| 區段 | 觀察到的高度 | 圖片場景 | 問題 |
|---|---:|---|---|
| 首屏 | 780 px | 04 天空 + Logo + 卡框 | 有環境與辨識度 |
| 品牌介紹 | 810 px | 無背景場景，只有獨立卡框 | 大片單色背景，與首屏脫節 |
| 卡展體驗 | 1,078 px | 無背景場景，只有內容配圖 | 淡色漸層與大量留白 |
| 全球展會 | 1,169 px | 無背景場景，只有篇章封面 | 韓國專頁再次介紹全球，視覺節奏重複 |
| 展會資訊 | 1,020 px | 05 城市 | 城市直到後段才出現；實際可載入與顯示 |
| 社群交流 | 800 px | 07 河面 | 圖片主要集中段落下部 |
| 常見問題 | 930 px | 無背景場景 | 長段列表又回到單色 |

首屏後的三段合計 **3,057 px**，未計中間 ticker。技術上底色為淡藍色與很接近的淡色漸層；使用者感受到的長段空白與單調有具體版面原因，不能用色碼差異否定問題。

`BrandIntroduction.tsx` 沒有背景場景，`ExperienceSection.tsx` 和 `EditionsSection.tsx` 也沒有掛載 PosterScene。`poster-scenes.css` 為這些區段設定了大段高度／padding 和近似底色。因此主因是素材使用與場景安排，不是需要新增缺圖 fallback。

## 下一版的構圖方向

- **01 是整頁的共同視覺來源**：保留春日首爾、河岸、櫻花、透明卡框、紅藍光與銀色細邊。每一個主要段落都要有明確的取景與物件安排。
- **04 天空 + 02 Logo** 完成開場；往下接 05 的城市及河岸，而不是先隔三大段單色區塊。
- **06 空卡框** 承接卡牌內容與互動，讓物件有用途；不同段落透過尺度與位置改變，避免重複貼同一完整海報。
- **03 攤商圖** 提供左紅右藍、手持卡片與細紋理的視覺參照。尚無無字乾淨版，不應把模板標題與日期直接當背景重複鋪在文字下面。
- **07 河面／步道** 收束到參加資訊、交通與 FAQ 的段落，讓頁尾仍保有韓國環境。
- 內容順序以韓國場為主：韓國主視覺 → 活動亮點 → 參展／活動資訊 → 交通與 FAQ。全球品牌介紹縮短，台灣照片明確標示為台灣回顧。
- 需要重新組合段落與圖片尺度；只改背景色或堆疊泛用玻璃卡片不能解決目前的單調問題。

## 下一版的可見驗收

1. 從首屏一路滑到頁尾，每個主要區段都有與 01／03 相關的構圖，不再出現連續数屏純淡色底。
2. 圖片在整段中可見，文字保持清楚，不用大面積白色遮罩蓋住場景。
3. 手機也有獨立取景，Logo 不變形，前景卡框不遮文字。
4. 韓國活動資訊有來源，素材編號在設計交接中可追溯。
5. 用實際桌面及手機尺寸的完整捲動審閱，不能只交首屏截圖或 build 成功。


## 本輪實作：韓國活動內頁

使用者確認外層 IP 網站已負責品牌與跨國導覽。韓國內頁改用上一屆台灣卡展的內容架構與資料作為暫時示範，套用韓國海報風格。

- 取消重複的全球品牌介紹、收藏文化宣言、跨國章節卡片。
- 內頁順序為主視覺與日期／時間／場地 → 三大活動亮點 → 合作夥伴與 29 個攤商標誌 → 地圖、交通與平面圖 → 三類 FAQ → 入場及挑戰賽參加資訊。
- 背景最終改為 09、10、11 三張完整 2048 × 1152 畫面：天空、首爾漢江、河岸地面各自保留完整 16:9 清晰度。第一個接點對齊山稜與城市天際線，第二個接點對齊河面與欄杆；只在對齊位置附近做窄幅羽化，不再出現完整圖片的硬切或大面積重影。
- 背景位移直接由頁面捲動比例計算，取消 lerp 緩動與前後延遲區間。圖文區採用高不透明銀藍表面、紅／藍細邊，避免文字直接壓在天空或水面上。
- 02 Logo 以原 PNG 轉為網頁用無損 WebP，RGB 像素逐一一致；SVG 外輪廓修復下緣誤切，裝置依實際顯示尺寸進行邊緣平滑。沒有 AI 重畫、放大後重壓縮或改色。
- 台灣暫用文案獨立存於 `src/flagship/korea/data/taiwanPreview.ts`，避免台灣回顧頁的修改影響韓國版。繁中、英文、韓文各自有完整內容。活動照片與合作夥伴沿用台灣素材，頁面明示來源。
- 韓國正式日期、場地、合作陣容與票務仍未定案；不把暫用日期或台灣票務連結當成韓國正式開放報名。
- 組件、文案、樣式分置於 `src/flagship/korea/`。停用舊韓國頁樣式入口，避免通用選擇器互相覆蓋。舊素材與來源檔保留。
